# Unverified drafts

These batches are new questions (q016–q030), essays (e03–e04) and gap-filling rules for
fl-business-entities, fl-family-law and fl-wills. Authors wrote them in the expansion workflow,
which was stopped before its two blind solvers and editor could check them. They are **not**
installed and **not** in `content/subjects`.

To finish one, have two independent solvers answer it blind, fix what they find, then merge it with
the same staging helper the workflow used: copy the file to `florida/staging/<id>.json` and run
`stage.py merge <id>`.
